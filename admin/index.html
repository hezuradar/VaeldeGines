Conectar con GitHub

El catálogo y las fotos se guardan en el repositorio de la web. Para que el panel pueda guardar los cambios necesita un token de GitHub. Se guarda una sola vez en tu cuenta y vale para cualquier móvil u ordenador.

  1. En GitHub: foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. En Repository access elige Only select repositories → hezuradar/VaeldeGines.
  3. En Repository permissions: Contents: Read and write y Actions: Read-only.
  4. Genera el token, cópialo y pégalo aquí.
